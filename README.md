# Learnly — Online Quiz & Learning Platform

A responsive frontend project based on the internship project described in Ashaaz Hussain's presentation. Built with HTML, CSS and vanilla JavaScript.

## Features
- Dashboard with course cards and learning overview
- Three topic-based learning modules with short lesson content
- Multiple-choice quizzes (5 questions per topic)
- Answer selection, previous/next navigation and submission
- Automatic score and percentage calculation
- Performance feedback and answer explanations
- Progress dashboard and quiz history saved in browser localStorage
- Responsive layout for desktop, tablet and mobile

## Run the project
1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. No installation or build step is required.

For the best development experience, open the folder in VS Code and use the Live Server extension.

## Project structure
- `index.html` — page structure and app views
- `styles.css` — visual design and responsive styling
- `app.js` — course data, quiz logic, scoring and progress tracking

## Scope note
This is a client-side prototype. Progress is stored in the current browser using localStorage. A production version could add a backend, database, authentication, instructor question management and cross-device progress sync.
